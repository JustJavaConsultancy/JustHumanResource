User Guide

Request Workflow

Create, submit, approve, track, and close organisational requests.

Open Requests

1. What The Request Workflow Does

The Request Workflow manages organisation-wide requests. A requester creates a draft, submits it for approval, and tracks its status. Approvers receive tasks and make decisions. HR/admin can see wider activity and close approved requests.

Create

Capture and draft request details.

Submit

Send into approval workflow.

Approve

Approve, reject, or return.

Track

Monitor status, timeline, comments.

2. Who Uses The Workflow

RoleWhat They Can Do
EmployeeCreate, edit, submit, track, and add comments to their own requests.
ApproverApprove, reject, or return assigned tasks.
HR/AdminView all requests, add internal comments, close approved requests, manage approval paths.

3. Quick Start

1

Open Requests

Tap Requests in the menu or go to /mobile/requests.

2

Create a draft

Go to My Requests, tap New Request, choose a type, fill fields, and tap Create Draft.

3

Review and submit

Open the draft, check details, add attachments if needed, then tap Submit.

4

Track progress

Use status badges, the approval timeline, comments, and activity log.

4. Request Types

Staff Requisition

Request new or replacement headcount. Requires staff requisition details.

File Request

Request access to or processing of files/documents. Requires at least one attachment before submission.

Asset Request

Request equipment, software, or tools. Requires at least one FAM asset.

Expense Reimbursement

Claim repayment for business expenses. Requires expense lines and a receipt.

General Request

Requests that do not fit another category. Minimal required fields.

5. Approval Flow

Submitted requests use the configured Flowable workflow. Approvers see tasks under Pending My Approval.

Approve

Moves to next approver or finalises.

Reject

Stops the workflow. Comment required.

Return

Returns for correction and resubmission.

6. Free Route

Free Route lets a requester send their request directly to a chosen employee rather than the configured line-manager or custom route.

When returned for correction, a request continues through the same route it originally used — Submit stays on the configured route, Send To stays on Free Route.
  • Free Route requests can be forwarded from employee to employee until a final decision.
  • Forward is only available for Free Route requests.
  • Approve on Free Route is final — it does not continue to any other configured route.

7. Status Guide

Draft

Created but not submitted. Requester can edit and submit.

In Approval

Assigned to approver(s). Awaiting decision.

Returned

Returned for correction. Requester should edit then resubmit.

Approved

All approval steps complete. HR/admin may close when fulfilled.

Rejected

Rejected and workflow ended.

Cancelled

Cancelled by the requester.

Closed

Approved and closed after fulfillment.

8. Troubleshooting

Cannot create a request

Confirm your login email is linked to an employee record.

No approval route configured

Ask HR/admin to check your primary reporting line.

File request will not submit

File requests require at least one attachment before submission.

Asset request will not submit

Requires at least one FAM asset selection with a valid quantity.

Expense reimbursement will not submit

Requires at least one expense line and a receipt or supporting attachment.
