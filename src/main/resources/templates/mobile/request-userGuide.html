User Guide

Request Workflow

Create, submit, approve, return, reject, and track requests from your phone.

Open Requests Quick Start

1. Overview

expand_more
The Request Workflow lets employees and approvers manage organization-wide requests. You can create drafts, submit for approval, attach files, select FAM assets, claim expenses, comment, and monitor progress from the approval timeline.

2. Quick Start

expand_more
1

Open Requests from the bottom nav or go to /mobile/employee/requests.

2

Tap + New Request, pick a type, and complete the form.

3

Create the draft, review, then tap Submit.

4

Track decisions in the approval timeline, comments, and activity log.

3. Request Types

expand_more
Staff Requisition

Request new or replacement headcount. Requires job and staffing details.

File Request

Access or process files/documents. Requires an attachment before submission.

Asset Request

Tools, software, equipment, or supplies. Requires a FAM asset selection, quantity, required date, and business justification.

Expense Reimbursement

Claim repayment for business expenses. Requires expense lines and a receipt/supporting attachment.

General Request

Anything that doesn't fit the other categories. Only common fields required.

4. Create And Manage

expand_more

Create Draft

  1. Tap + New Request.
  2. Select request type and priority.
  3. Enter title and description.
  4. Fill type-specific fields.
  5. Tap Create Draft.

Submit And Track

  1. Open the request detail page.
  2. Add attachments, FAM assets, or expense lines as required.
  3. Tap Submit.
  4. Watch status, comments, and timeline.

Edit A Request

  1. Find the request in your list.
  2. Tap the edit icon (draft or returned-for-correction requests only).
  3. Update the details and tap Save Changes.
  4. Editing only saves details — reopen and tap Submit or Send To to resend it.

5. Approval Flow

expand_more

Requests are routed through the approval workflow. If a task is assigned to you, it appears under Pending Approvals.

ApproveMoves the request forward or completes approval.
RejectStops the workflow. Comment required.
ReturnSends back for correction. Comment required.

6. Free Route

expand_more

Free Route is a separate way to get a request approved. It sends the request to one specific employee you choose, instead of your normal approval route.

When a request is returned for correction, it continues through the same route family it originally used. A request first submitted normally is resubmitted with Submit. A request first sent through Free Route is sent again with Send To.

Submit

Follows your normal configured approval route (manager chain or HR-configured path). Available while the request is a draft, or returned after previous normal submission.

Send To

Sends directly to one employee you select. Available while the request is a draft, or returned after previously being sent this way.

  • The recipient can Approve, Reject, Return, or Forward the request.
  • Forward is only available on Free Route requests.
  • Forwarding can chain from person to person until someone approves, rejects, or returns.
  • Approving a Free Route request finalizes it as approved.
  • Rejecting stops it immediately.
  • Returning sends it back to you for correction.
  • You cannot select yourself or the current holder as the next recipient.
Free Route is chosen by you on an individual request — it is not something HR/admin configures for a request type.

8. Troubleshooting

expand_more

I cannot create a request

Confirm your login email is linked to an employee record.

No approval route is configured

Ask HR/admin to check your primary reporting line.

File request will not submit

Upload at least one supported attachment first.

Asset request will not submit

Select at least one asset from FAM, enter a valid quantity, required date, and business justification.

Expense reimbursement will not submit

Add at least one expense line and upload a receipt or supporting document first.
