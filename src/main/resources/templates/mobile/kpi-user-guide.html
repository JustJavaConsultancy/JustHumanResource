KPI & Appraisal User Guide

Complete guide for KPI definition, assignment, measurement, appraisal, and reporting.

Module Overview

expand_more

The KPI module runs as a sequence: Definition → Assignment → Measurement → Appraisal → Reports.

  • Primary screen: /kpi (tabs: Definitions, Assignments, Measurements, Appraisal)
  • Reports screen: /kpi-report/dashboard
  • API workflow: /api/appraisals/*

1) KPI Definition

expand_more
  1. 1Open KPI Definitions tab.
  2. 2Create KPI with: Code, Name, Description, Category, Target Value, Unit, Impact Salary.
  3. 3Submit. New KPI is automatically marked active.

Categories: Productivity/Attendance/Quality. Units: Percentage/Number/Hours.

2) KPI Assignment

expand_more
  1. 1Open KPI Assignments tab; choose scope: Employee, Job Step, or Department.
  2. 2Add KPI rows with weight and mandatory flag.
  3. 3Submit via /kpi/assign.
Weight rule: total active weight for the scope cannot exceed MAX_KPI_WEIGHT (default 1.0).

3) KPI Measurement

expand_more
  1. 1Open KPI Measurements.
  2. 2Select employee to load their effective assigned KPIs.
  3. 3Enter period (YYYY-MM) and actual values, then submit.
  4. 4Existing same employee/KPI/period entries are skipped; edit from measurements table.

Actual value must be zero or positive.

Scoring Logic

  • Per KPI score: (actual / target) × 100, capped at 100.
  • If target ≤ 0: score is 0.
  • Salary-impact KPI score: avg of impactSalary=true KPIs; fallback = 100 if none.

4) Appraisal Flow

expand_more

A. Appraisal Cycle

Create cycles via POST /api/appraisals/cycles with year and quarter (Q1–Q4). A cycle spans 3 months.

B. Draft Appraisal

Draft appraisal computes KPI score from measurements in cycle period. POST /api/appraisals/draft.

C. Manager Review

Manager enters score/comment from Appraisal tab and submits workflow task.

D. Employee Self-Review

Employee self-score/comment captured in workflow and visible to manager.

Final Score Formula

(kpiScore × 0.7) + (managerScore × 0.3)

If manager score is missing, final score = KPI score.

Outcome Bands

  • EXCEEDS_EXPECTATION: score ≥ 85
  • MEETS_EXPECTATION: 70 – 84
  • NEEDS_IMPROVEMENT: 50 – 69
  • UNDERPERFORMING: < 50

Operational Checklist

expand_more
  1. 1.Define KPIs with correct targets, units, and salary impact flags.
  2. 2.Assign KPIs by scope; confirm total active weight is within configured max.
  3. 3.Capture measurements each period for assigned KPIs only.
  4. 4.Create/maintain appraisal cycles; ensure measurement data exists for cycle period.
  5. 5.Complete manager and employee review tasks.
  6. 6.Review final scores, outcomes, and KPI reports for action planning.
